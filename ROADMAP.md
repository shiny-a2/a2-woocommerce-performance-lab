# Roadmap

This repository is a public engineering showcase. The roadmap tracks documentation, samples, and safe architecture references, not production source release.

## Near Term

- Add a small request-classification test fixture for cache bypass rules.
- Add sanitized examples for cache invalidation after product and Elementor changes.
- Split the performance logger sample into writer, sampler, and formatter classes.
- Add a short ADR explaining why guest-only microcache was preferred over broader page caching.

## Later

- Add synthetic screenshots for diagnostics screens after privacy review.
- Add a compatibility note for WooCommerce HPOS, Store API, and Elementor-heavy pages.
- Add a sample maintenance command for transient-family cleanup.
- Document rollback paths for disabling each module independently.

## Not Planned

- Publishing production MU-plugin source.
- Publishing real route logs, product IDs, order IDs, or internal hostnames.
- Turning this into a general-purpose WordPress performance plugin.

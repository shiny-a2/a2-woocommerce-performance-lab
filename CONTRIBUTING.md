# Contributing

This is a portfolio showcase, so contributions should improve clarity, safety, or technical review value.

Good contributions:

- documentation fixes;
- safer sample boundaries;
- test fixtures for pure logic;
- diagrams that explain request flow or maintenance flow.

Not accepted:

- production source dumps;
- real logs or private URLs;
- broad plugin feature requests;
- changes that make the repo look like an installable product when it is not.
